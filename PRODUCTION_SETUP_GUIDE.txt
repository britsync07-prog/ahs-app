3. HOW TO RELEASE A NEW VERSION
-------------------------------
A) Update the version number in `vault-desktop-tauri/src-tauri/tauri.conf.json` 
   and `vault-desktop-tauri/package.json`.
B) Commit and push the changes.
C) Create a "New Release" on GitHub with a tag (e.g., v0.1.1).
D) GitHub Actions will build the signed installer and attach it to the release.
E) Users will receive a pop-up in their app to update automatically!
