SECRET NAME:  TAURI_SIGNING_PRIVATE_KEY
SECRET VALUE: Use the private key that matches the installed production public key `C7BE727065470402`.

SECRET NAME:  TAURI_SIGNING_PRIVATE_KEY_PASSWORD

IMPORTANT: Do not generate a new updater signing key for normal releases.
Installed desktop apps trust the public key embedded in
`vault-desktop-tauri/src-tauri/tauri.conf.json`. GitHub Actions must sign
with the matching private key, or existing users will reject the update.

3. HOW TO RELEASE A NEW VERSION
-------------------------------
A) Update the version number in `vault-desktop-tauri/src-tauri/tauri.conf.json`
   and `vault-desktop-tauri/package.json`.
B) Commit and push the changes.
C) Create a "New Release" on GitHub with a tag (e.g., v0.1.1).
D) GitHub Actions will build the signed installer and attach it to the release.
E) Users will receive a pop-up in their app to update automatically!
