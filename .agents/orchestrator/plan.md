# Implementation Plan: WebAuthn with PIN Fallback

This plan details the steps for implementing robust WebAuthn biometric authentication with seamless PIN fallback in the zero-knowledge vault web auth node.

## Architecture & Context
- **Codebase**: React + TypeScript client (Vite, Tailwind).
- **Target Platform**: Mobile (iOS Safari/WKWebView and Android Chrome) and Desktop.
- **Constraints**:
  - Secure context (HTTPS) requirements for WebAuthn.
  - Browser-level user gesture (activation) requirements for WebAuthn API calls.
  - Hardware biometric checks (`isUserVerifyingPlatformAuthenticatorAvailable`).

## Milestones

### Milestone 1: Exploration & Codebase Analysis
- **Goal**: Research current hooks/components (`useWebAuthn.ts`, `Shield.tsx`, `BiometricPrompt.tsx`, `PinPad.tsx`) and local web server constraints.
- **Verification**: Exploration report generated by read-only Explorer subagents detailing current issues and path to implementation.

### Milestone 2: E2E Test Suite and Test Infrastructure
- **Goal**: Define `TEST_INFRA.md` and write a test harness or unit tests. Implement a structured test plan.
- **Verification**: `TEST_INFRA.md` is populated, test files created or planned.

### Milestone 3: Implementation of WebAuthn & PIN Fallback
- **Goal**:
  1. Add WebAuthn support and platform authenticator availability checks.
  2. Implement seamless PIN fallback on cancellation or lack of support.
  3. Ensure user gesture preservation during websocket-triggered triggers (e.g. clicking to trigger biometrics).
  4. Make biometric enrollment skippable during onboarding, allowing PIN-only registration.
- **Verification**: Build succeeds and unit tests pass.

### Milestone 4: Verification, Hardening, and Forensic Auditing
- **Goal**: Verify all acceptance criteria are met, and run Forensic Auditor.
- **Verification**: Verification and audit pass clean.
